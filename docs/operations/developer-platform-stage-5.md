# Mini App integration operations

The former Stage 5 redirect/callback integration has been removed. Use
[Mini App Auth Bridge](miniapp-auth-bridge.md),
[Render configuration](miniapp-auth-bridge-render.md), and
[Sandbox automatic login](sandbox-auto-login.md).

Historical design/test evidence remains in the Stage 5 specification and handoff;
it does not describe supported routes or deployment configuration for this revision.
Legacy data is handled by the reversible
[store archive](miniapp-legacy-sso-cleanup.md). No Production data is deleted.
